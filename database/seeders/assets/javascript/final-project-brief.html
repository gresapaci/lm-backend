Final Project: Weather Dashboard

Build a single-page weather dashboard using only HTML, CSS and vanilla JavaScript (no frameworks). The project combines everything from the course: DOM manipulation, events, async/await with fetch, modules, classes, error handling and localStorage.

API

Use the free Open-Meteo APIs — no API key required.

// 1. City name → coordinates
https://geocoding-api.open-meteo.com/v1/search?name=Prishtina&count=1

// 2. Coordinates → weather
https://api.open-meteo.com/v1/forecast?latitude=42.66&longitude=21.17&current=temperature_2m,wind_speed_10m,weather_code&daily=temperature_2m_max,temperature_2m_min&timezone=auto

Required features

  1. Search form: the user types a city and sees the current temperature, wind speed and a short description.
  2. A 7-day forecast list (min / max temperature per day).
  3. Loading state while requests are in progress and a friendly error message if the city is not found or the network fails.
  4. "Recent searches" — the last 5 cities, saved in localStorage, clickable to search again.
  5. Toggle between °C and °F without making a new request.

Suggested structure (ES modules)

index.html
css/style.css
js/main.js          // wires everything together, event listeners
js/api.js           // export async function getCoordinates(city), getWeather(lat, lon)
js/ui.js            // export function renderCurrent(data), renderForecast(days), showError(msg)
js/storage.js       // export function loadRecent(), saveRecent(city)
js/units.js         // export const toFahrenheit = (c) => c * 9 / 5 + 32

Load it with <script type="module" src="js/main.js"></script> and serve the folder with a local server (e.g. VS Code "Live Server" or npx serve) — modules do not work over file://.
